# Project 1: To-Do List

## 📋 About the Project

This is a simple To-Do List application built with Python. It helps users manage their daily tasks by allowing them to add, edit, complete, and delete tasks efficiently.

---

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- View all tasks in a list

---

## 🛠️ Technologies Used

- Python
- (Optional) Flask or Tkinter for GUI/web interface
- (Optional) SQLite or file-based storage

---

## 💻 Getting Started

### Prerequisites

- Python 3.x installed on your system

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd PRJOECT-1-TO-DO-LIST
   ```
3. **(If applicable) Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

### Running the Application

- **If it's a command-line app:**
  ```bash
  python app.py
  ```
- **If it's a Flask web app:**
  ```bash
  python app.py
  ```
  Then open your browser and go to `http://localhost:5000`
